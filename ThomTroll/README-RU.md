# ThomTroll для iPhone — исходный проект 0.1

**Это исходный проект, а не готовый IPA.** В среде подготовки нет macOS/Xcode,
поэтому компиляция, тесты Swift и установка на iPhone здесь не выполнялись.
Проверены синтаксис Swift, структура проекта Xcode, plist и сценарии упаковки.
Первая настоящая компиляция выполняется workflow ниже. При ошибке потребуется
исправление по журналу GitHub Actions. Совместимость с Scarlet и ЦЗ не проверена.

## Что сделано

- Приложение с созданием, редактированием, удалением и избранными шаблонами.
- Импорт TXT до 5 МиБ: UTF-8, UTF-16 с BOM, CP1251.
- Отдельная тёмно-красная клавиатура: русский, английский, цифры/символы,
  пробел, регистр, удаление с удержанием, переключение клавиатур через 🌐.
- Префикс редактируется прямо в клавиатуре, в том числе вставкой из буфера.
- Выбор шаблона кружком, вставка одной строки или ввод строк по таймеру.
- Интервал 0.5, 1 или 3 секунды; старт через 3 секунды; пауза/продолжение;
  стоп сбрасывает позицию; рандом без одинаковых строк в одном проходе;
  повтор с перерывом 5 секунд.
- Фразы вставляются целиком, поэтому половинчатой фразы при паузе нет.
- Журнал последних ошибок в клавиатуре. После закрытия клавиатуры журнал
  не сохраняется. Шаблоны сохраняются в локальных файлах атомарно.
- Сетевых запросов, аналитики и серверов в коде нет.

**Это не полный перенос Android-версии.** Видео, музыка, фоновые клики,
прицел отправки и заставка из Android не включены.

## Ограничение отправки

«Ввод ↵» вызывает `textDocumentProxy.insertText("\n")`. Это вставка символа
новой строки, а не аппаратное нажатие Enter и не команда отправки сообщения.
Будет ли сообщение отправлено, определяет приложение/игра.

**Работа отправки в «Целуй и знакомься» на iPhone не подтверждена.**
Сначала проверяй одной строкой вручную. Не включай повтор, пока не проверишь
поведение поля. Если приложение превращает ↵ в перенос строки, автоввод
будет добавлять строки в черновик; он не нажмёт чужую кнопку отправки.
При скрытии клавиатуры набор прекращается; автоматизация в фоне не работает.

## Как получить IPA без собственного Mac

В проект уже включён `.github/workflows/build-ipa.yml`. Он запускает стандартный
macOS runner, тесты Swift, Xcode build для настоящего iPhone arm64, а затем
упаковывает приложение вместе с расширением клавиатуры в IPA.

1. Распакуй архив на Windows.
2. На GitHub создай новый **публичный** репозиторий без личных данных.
   Публичность нужна, если хочешь использовать бесплатные стандартные runner.
3. Загрузите **содержимое папки проекта в корень репозитория**, включая `.github`.
   Не загружайте ZIP как один файл и не оставляйте дополнительную папку-обёртку.
   В корне должны быть `.github`, `App`, `Keyboard`, `Shared`, `scripts`,
   `ThomTroll.xcodeproj` и этот README.
4. Открой **Actions → Build iPhone IPA → Run workflow → Run workflow**.
5. Дождись зелёного результата. Если сборка красная, открой упавший шаг:
   нужен его текст ошибки, чтобы исправить проект.
6. Внизу страницы успешного запуска скачай **Artifacts → ThomTroll-unsigned-IPA**.
7. Распакуй скачанный ZIP. Внутри должен находиться `ThomTroll-unsigned.ipa`.

По документации GitHub стандартные hosted runner в публичных репозиториях
предоставляются бесплатно. Для приватных репозиториев и других классов runner
могут действовать квоты/оплата. Workflow не публикует приложение в App Store,
не использует Apple ID и не содержит секретов подписи.

Источник: https://docs.github.com/en/billing/concepts/product-billing/github-actions

## Scarlet

Результат сборки **не подписан**. Его нужно подписать при установке.
Scarlet должен подписать **и приложение, и вложенное расширение клавиатуры**.
Не включайте удаление расширений/PlugIns: без `ThomTrollKeyboard.appex`
приложение может открыться, но клавиатуры в настройках не будет.

Возможность установки зависит от версии Scarlet, его сертификата, разрешений
подписи и версии iOS. Действующий сертификат не гарантируется; при отзыве
установленные приложения могут перестать работать. IPA не является обходом
проверки подписи Apple и сам по себе не устанавливается.

## Включение и перенос шаблонов

1. После успешной установки: **Настройки → Основные → Клавиатура → Клавиатуры →
   Новые клавиатуры → ThomTroll**.
2. Для импорта буфера включи **Разрешить полный доступ** у ThomTroll.
   Без него базовая клавиатура и пробный шаблон работают, а чтение буфера
   для импорта может быть недоступно. Код не использует доступ к интернету.
3. В приложении создай/импортируй шаблоны и нажми **Передать коллекцию в клавиатуру**.
4. В чате удерживай 🌐, выбери ThomTroll → **Шаблоны → Импорт → Заменить?**.
   Коллекция клавиатуры заменится скопированной коллекцией целиком, включая префикс.
5. Нажми кружок у шаблона. **Строка** вставит фразу без переноса.
   **Ввод ↵** вставит перенос/попробует отправку в зависимости от приложения.
6. **Старт** вставляет целые фразы с ↵ по таймеру. **Пауза** сохраняет позицию,
   **Продолжить** берёт следующую строку, **Стоп** сбрасывает её на начало.

Коллекции приложения и клавиатуры хранятся отдельно: это осознанный отказ от
App Groups, которые осложняют бесплатную переподпись. После изменений в
приложении повтори передачу. Изменённый прямо в клавиатуре префикс действует
сразу, но последующий импорт из приложения заменит и его.

Некоторые приложения не допускают сторонние клавиатуры; в паролях iOS заменяет
их системной. Если ThomTroll есть в настройках, но отсутствует в конкретной
игре, проверить разрешение сторонних клавиатур должен разработчик игры.

## Для разработчика

- iOS 16+, UIKit extension + SwiftUI companion app. Сторонних зависимостей нет.
- Открыть `ThomTroll.xcodeproj`, общая схема `ThomTroll`.
- Сборка: `bash scripts/build-ipa.sh` на macOS с Xcode.
- Тесты модели: `bash scripts/test.sh` на системе со Swift.
- Изменение структуры проекта: `python3 scripts/generate_project.py`.
- Скрипт упаковки отвергает отсутствующие/неисполняемые файлы: проверяет
  настоящий arm64 Mach-O у приложения и у расширения.
- Для TestFlight нужна отдельная подписанная сборка с Apple Developer.
